## Descrição do Projeto
Este projeto simula um **sistema de cálculo de comissão para vendedores**, contemplando diferentes níveis, metas mensais, bônus e alertas de desempenho.  
O objetivo é fornecer uma **base escalável e modular** para exercícios de lógica de programação, prática de estruturas condicionais, loops e operadores aritméticos em JavaScript.

O projeto está sendo construido e estruturado para facilitar a **evolução contínua**, permitindo adicionar novas funcionalidades sem impactar o código existente.

---


## Tecnologias Utilizadas
- **JavaScript (Node.js)** – lógica de programação, condicionais, loops, operadores aritméticos.
- **JSON** – armazenamento e leitura de dados de vendedores.
- **Console** – saída de resultados para o usuário.

---

## Funcionalidades (projeto em andamento)

1. **Cálculo Básico de Comissão (`index.js`)**
   - Determina a comissão com base no nível do vendedor.
   - Verifica se a meta do mês foi atingida.
   - Imprime no console o valor da comissão e a mensagem correspondente.
